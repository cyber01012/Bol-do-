# Documentation Style Guide

## File Naming
- Use kebab-case for all files: `my-document.md`
- Prefix with category if needed: `agent-xxx.md`, `system-xxx.md`

## Headings
- H1 (`#`) — File title only, once per file
- H2 (`##`) — Major sections
- H3 (`###`) — Subsections
- H4 (`####`) — Implementation details

## Code Blocks
- Always specify language: ` ```typescript `, ` ```json `, etc.
- Use meaningful variable names

## Tables
- Use pipes for alignment
- Include header separator

## Cross-linking
- Use relative paths: `[Link](../shared/api-contracts.md)`
- Always include descriptive anchor text
