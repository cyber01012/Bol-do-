# Shared Output Types

This file defines reusable outputs generated by AI workflows and backend systems.

---

# Intent Output

Type:
Object

Purpose:
Represents extracted user intent from natural language input.

Structure:

{
  "service_type": "",
  "location": "",
  "preferred_time": "",
  "urgency": "",
  "budget_preference": "",
  "confidence_score": 0
}

Example:

{
  "service_type": "AC Technician",
  "location": "DHA Phase 5",
  "preferred_time": "tomorrow morning",
  "urgency": "high",
  "budget_preference": "low",
  "confidence_score": 0.92
}

---

# Ranked Providers Output

Type:
Array<Object>

Purpose:
Represents ranked provider recommendations.

Structure:

[
  {
    "provider_id": "",
    "name": "",
    "service_type": "",
    "ranking_score": 0,
    "distance_km": 0,
    "estimated_price": 0,
    "rating": 0,
    "availability": true
  }
]

Example:

[
  {
    "provider_id": "P001",
    "name": "Ali AC Services",
    "service_type": "AC Technician",
    "ranking_score": 92,
    "distance_km": 2.1,
    "estimated_price": 2500,
    "rating": 4.8,
    "availability": true
  }
]

---

# Booking Confirmation Output

Type:
Object

Purpose:
Represents successful booking confirmation.

Structure:

{
  "booking_id": "",
  "booking_status": "",
  "provider_name": "",
  "scheduled_time": "",
  "estimated_price": 0
}

Example:

{
  "booking_id": "B102",
  "booking_status": "confirmed",
  "provider_name": "Ali AC Services",
  "scheduled_time": "2026-05-18T10:00:00Z",
  "estimated_price": 2500
}

---

# Pricing Output

Type:
Object

Purpose:
Represents pricing breakdown generated by the pricing system.

Structure:

{
  "base_price": 0,
  "distance_fee": 0,
  "urgency_multiplier": 0,
  "discount": 0,
  "final_price": 0
}

---

# Notification Output

Type:
Object

Purpose:
Represents generated notifications and reminders.

Structure:

{
  "notification_type": "",
  "message": "",
  "timestamp": ""
}

---

# Voice Output

Type:
Object

Purpose:
Represents AI-generated voice responses.

Structure:

{
  "message_text": "",
  "audio_generated": true,
  "language": ""
}

---

# Important Rules

- All systems must follow these output structures consistently.
- Avoid creating duplicate output structures in other files.
- Backend and frontend contracts must remain aligned.
