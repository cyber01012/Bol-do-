# System Rules

- Use Flutter for all frontend development.
- Use FastAPI for backend APIs.
- Use Firestore as primary database.
- All APIs must return JSON.
- Every workflow must generate trace logs.
- Keep UI clean and minimal.
- Avoid unnecessary dependencies.
- Use modular architecture.
- Use reusable components where possible.
- All provider data will be mock data.
- Keep Firebase collections normalized.
- Handle edge cases and fallback scenarios.
