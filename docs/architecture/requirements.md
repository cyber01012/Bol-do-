# Requirements

# Functional Requirements

- User can enter service requests in Urdu, Roman Urdu, or English.
- System extracts:
  - service type
  - location
  - time
  - urgency
  - budget preference

- System discovers providers.
- System ranks providers using multiple factors.
- System generates pricing.
- System simulates booking.
- System handles follow-ups.
- System handles disputes.
- System generates agent logs.
- System should support voice input.
- System should support AI-generated voice responses.
---

# Non Functional Requirements

- Mobile-first design
- Fast response time
- Modular architecture
- Scalable backend
- Error handling support
- Clean UI/UX
