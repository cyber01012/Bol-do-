# BolDo — AI Service Orchestrator
<img width="659" height="749" alt="image" src="https://github.com/user-attachments/assets/aec09d56-7a7b-473f-8154-c6ebaeb7a327" />

BolDo is an AI-powered service orchestration platform focused on home services such as:
- AC Technicians
- Electricians
- Plumbers
- Carpenters
- Home Cleaning
- Appliance Repair
- Painters

The system uses an agentic AI workflow to automate:
- multilingual intent understanding
- provider discovery
- intelligent ranking
- dynamic pricing
- booking simulation
- notifications
- follow-up automation
- dispute handling

Built for:
Google Antigravity Hackathon — Challenge 2

---

# Core Features

- Urdu / Roman Urdu / English support
- AI-powered provider matching
- Dynamic pricing engine
- Booking lifecycle simulation
- AI reasoning traces
- Voice input/output support
- Dispute handling workflows
- Firebase backend integration
